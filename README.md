# Cybersecurity & Ethical Hacking Internship — Task 1

## Foundation & Environment Setup

This repository contains the work completed for **Task 1** of the Cybersecurity & Ethical Hacking Internship at **ApexPlanet Software Pvt. Ltd.**

## Objective

The objective of Task 1 was to build fundamentals in:

- Cybersecurity
- Networking
- Cryptography
- Linux fundamentals
- Security tools
- Cybersecurity laboratory setup
